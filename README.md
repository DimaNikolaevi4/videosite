# videosite — концепция иммерсивного сайта

**Идея:** сайт-путеводитель, в котором пользователь проходит сцены-погружения: видео, анимация и интерактивный диалог вместо обычной «страницы с текстом». Замысел описан в `1.md` — сценарий, структура сцен, приёмы вовлечения.

## Что реализовано

**Ничего, кроме концепции.** В репозитории два файла:

| Файл | Что это |
|---|---|
| `1.md` | Концепция: «Иммерсивный веб-сайт: путеводитель по созданию» — погружение через видео, анимацию и интерактивный диалог (13 КБ) |
| `plan.json` | Заглушка для общего календаря («срочных дел нет») |

Кода, макетов, прототипов нет. Это репозиторий-замысел, а не разработка.

## Статус

- Степень реализации: **0%** — только идея.
- В календаре задач репозиторий числится, но с заглушкой: активных задач нет.
- Если идея станет актуальной — начинать нужно с прототипа одной сцены (видео + интерактивный шаг), а не с полного сайта.
